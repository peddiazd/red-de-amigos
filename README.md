# Red de Amigos AI

**Análisis de relaciones usando grafos e inteligencia artificial**

### Nombre de la actividad
Red de amigos: análisis de relaciones usando grafos e inteligencia artificial

### Propósito de la actividad
El propósito de esta actividad es que los estudiantes desarrollen una aplicación web o una aplicación en Python que permita representar relaciones entre personas usando grafos.

A partir de información como amigos cercanos, amigos de amigos, hobbies, deportes, comunidad e intereses, el sistema deberá construir una red visual y sugerir posibles conexiones entre personas.

### Contexto del problema
Una institución educativa quiere crear una herramienta sencilla para analizar las relaciones entre sus estudiantes.

La herramienta debe permitir:
- Registrar una persona, sus amigos cercanos y los amigos cercanos de esos amigos.
- Añadir información adicional: Comunidad o grupo, Hobbies, Deportes, Gustos personales, Intereses académicos o culturales.

El sistema construye una red visual (nodos = personas, aristas = amistades) y sugiere nuevas amistades analizando similitudes.

### Funcionalidades
- Registro de personas y atributos
- Gestión de amistades bidireccionales
- Visualización del grafo
- Sugerencias inteligentes de amistad (amigos de amigos + similitud Jaccard)
- Análisis de la red

Tecnologías: Python + NetworkX + Matplotlib + (opcional) Streamlit

Proyecto desarrollado como parte de la actividad académica de grafos e IA.
